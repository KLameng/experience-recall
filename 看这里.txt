这个工具叫「经验与记忆管理工具」，也写作「记忆与经验管理工具」——两种叫法指的是同一件东西。

> 文件夹名叫 `experience-recall`，那是它在这个平台的**登记号**，不是它的名字。
> 平台按登记号同步和识别，本地改文件夹名会被同步改回来（实测过，一分钟内被还原）。
> 所以：**名字看中文，路径照抄英文**。

**这一份是空库版**：程序齐、账齐，但经验卡 0 张、记忆 0 条、项目 0 个、资产册 0 项。
它是给你从零开始记的，不是坏包。里面没有任何别人的数据。

它由两个文件夹组成，必须并排放在同一个地方：

    .user_skills/          放说明书和程序（含记忆程序 core/）
    experience/            放仓库（经验卡、三本账、记忆）

    .user_skills/experience-recall/recall.py    ← 程序在这儿
    .user_skills/experience-recall/core/        ← 记忆程序在这儿
    experience/                                 ← 仓库在这儿，在程序的上一层
    experience/memory/                          ← 记忆（过程记录）在这儿

**保持这个上下关系，不要拆开、不要改层级。** 程序靠"我在哪"自己算出仓库在哪。
摆平了（两个文件夹随便放两个地方），程序不会报错，会跑去别处找仓库——这是唯一要小心的地方。

---

拿到包的人，三步：

1. 解压到任意一个空文件夹。解压出来就是上面那个结构，已经是对的，什么都不用改。
2. 跑自检：
       Windows:   双击 自检.cmd
       Mac/Linux: sh 自检.sh
       或者任一手工方式:  python .user_skills/experience-recall/自检.py
3. 看到「能用（空库）」并退出码 0，就装好了。

---

装好之后能干什么：

    python .user_skills/experience-recall/recall.py search 关键词    查历史经验
    python .user_skills/experience-recall/recall.py log status       看账记到哪了
    python .user_skills/experience-recall/recall.py stats            数库里有多少东西
    python .user_skills/experience-recall/recall.py mem stats        数记忆里有多少条
    python .user_skills/experience-recall/recall.py mem search --q 关键词   查某件事的过程
    python .user_skills/experience-recall/recall.py asset scan       扫一遍，把技能和知识库记成账
    python .user_skills/experience-recall/recall.py asset search 关键词  找资产（哪些技能干这件事）
    python .user_skills/experience-recall/recall.py asset check      体检：谁没版本号、谁改了没升版

不用装任何东西，不用联网，不用起服务。Python 3 自带就够。

## Windows 用户先看这一行

不要用资源管理器双击解压（中文文件名会乱码）。把本包和 `解压.ps1` 放同一个文件夹，右键 `解压.ps1` →「使用 PowerShell 运行」，它会按 UTF-8 解压并自动跑自检。

## 空库版的三件「看着像坏了、其实正常」

1. **闸起不来**：`recall.py gate` 会报「GATE 无法判定：0 根探针」并 exit 2。空闸不等于通过，这是设计如此。
2. **没有探针批准表**：0 张卡就没有探针可批，`deploy_check.py` 会报「批准表不可用」。等你自己建了卡并 `approve` 之后才会绿。
3. **资产册是空的**：它是「本机扫描结果」，换台机器扫出来必然不同，所以包里故意不带。跑一次 `recall.py asset scan` 就有了。

## 一条硬规矩

**记账前先确认库在哪台机**：`recall.py where`。多台机器同时写一座库，号会撞、账会分叉；要么只让一台写，要么每台各用各的库。
